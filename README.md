# Managish – Kitchen & Inventory

Tablet web app for Managish (Aljada + Cloud Kitchen): stock, deliveries & POs, kitchen requests, productions, waste/charity, cloud kitchen transfers, inspection, reports and voice assistant.

- `index.html` – the whole app (open it in Safari/Chrome, "Add to Home Screen").
- `status.json` – remote pause switch: `{"state":"running"}`, `"paused"` or `"stopped"`.
- `voice-worker.js` – optional Cloudflare Worker for the Level 2 AI voice.
